**Phụ trách:** Nguyễn Đinh Huyền Mai (FE3)

## Phạm vi công việc

### Màn 2 — Home & Desk View

- Khối bàn làm việc:
  - Laptop
  - Cốc trà
  - Ảnh
  - Currently Reading
  - From the Mailbox

- Phần dưới:
  - Hall of Fame
  - Recent Leaves
  - Quick Note

### Kết nối API

- Hall of Fame — lấy 2 bài nổi bật
- Recent Leaves — lấy 4 bài mới nhất
- Quick Note — chuyển tới Whisper Box để gửi note

### Xử lý dữ liệu

- Không có dữ liệu
- Không đủ dữ liệu
- Nội dung quá dài
- Ảnh bị lỗi
